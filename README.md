# Проект автотестов для API сервиса аренды электросамокатов.

# Описание
Клиент создает заказ.
Проверяется, что по треку заказа можно получить данные о заказе.

## Тесты
- Создание заказа и получение по трек-номеру
- Создание заказа без цвета
- Создание заказа с минимальными данными
- Создание заказа с двумя цветами
- Создание заказа с серым цветом
- Создание заказа с длинным комментарием
- Создание заказа с разным сроком аренды

# Структура
- configuration.py – базовый URL и пути API.
- data.py – шаблоны тестовых данных (создание пользователя).
- sender_stand_request.py – функции для отправки запросов к API.
- create_order_test.py – файл с тестами (pytest).
- .gitignore – список игнорируемых файлов.
- README.md – описание проекта.

# Требования
- Python 3.7+
- Установленные библиотеки: requests, pytest

# Установка зависимостей
bash
pip install requests pytest

# Запуск тестов
Сервер запущен и доступен по адресу, указанному в configuration.py (переменная BASE_URL).

Выполнить команду в терминале:

bash
python -m pytest create_order_test.py -v
